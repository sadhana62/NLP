    AI Dialogue Engine Comparison

    Generative LLM vs. Classical NLP (Zero LLM) Architecture Inspector
    ⚡

    Generative LLM Mode

    Autoregressive Transformer with RAG Persona Ingestion

    • Inference: Ollama Local Server (Qwen 2.5 / Gemma 3)
    • Pipeline: User query → TF-IDF Passage Retrieval → Injected into First-Person Persona System Prompt → Neural Token Probability Sampling.
    • Strengths: Fluid conversational dialogue, creative empathy, expressive literary roleplay.
    • Trade-offs: Requires local GPU/Ollama server; probabilistic response generation.
    🏛️

    Classical NLP Mode

    Information Retrieval + TF-IDF Vector Space Model + Salient Dialogue Extractor

    • Inference: Pure Classical NLP (Zero Neural Networks / Zero LLM)
    • Pipeline: Regex Intent Matcher → NLTK VADER Sentiment → TF-IDF Cosine Similarity → Direct Book Dialogue Extraction → Slot-Filling Synthesis.
    • Strengths: Instantaneous (<5ms), 100% deterministic, verbatim canonical citations, zero hallucination risk.
    • Trade-offs: Template-governed structure; quotes original text rather than improvising new wording.
